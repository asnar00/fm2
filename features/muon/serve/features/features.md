## spec

The tree that built the running product is publicly browsable beside it. At deploy, the explorer's own renderer statically exports every node — tree, spec + code, provenance transcript — into `site/features/<path>/index.html`; the serve base gains a directory-index fallback and the gate lists `/features/` public (`/gate/public`: a shareable artefact, ftr's stance). What's served is generated by the same deploy that built the binary serving it: the published tree is provably the source of the live app. Refinements: `/drawers` (phone layout), `/place` (transcript positioning), `/tidy` (support folders), `/fmdoc` (orientation).
