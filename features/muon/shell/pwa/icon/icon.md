## spec

Proper app-tile identity: ᕦ(ツ)ᕤ in white on a black tile, rendered at 2048px with macOS's own text engine (same system font fallback the browser uses, so the tile matches the in-app logo), downscaled to the manifest's 192/512 sizes. Spans ~64% of the tile so iOS's corner mask doesn't clip it. iOS caches a tile at install time — icon changes need remove + re-add. `/everypage` covers where the icon must be declared.

## user

The installed app's tile is the logo. New installs pick icon changes up automatically; existing tiles keep theirs until re-added.

## code description

This node owns `assets/icon-192.png` and `assets/icon-512.png` — generated by a JXA/Cocoa script (NSImage + attributed string, measured to span 64%) and `sips` downscaling. The linker copies them into the site alongside the shell's assets; the manifest and each page's `apple-touch-icon` link reference them.
