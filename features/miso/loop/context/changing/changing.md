## spec

Grouping node, created under the 4–6 children rule: `context` stood at six when `/world-cache` arrived, and `converge.md` had already named the honest split — *holding* from *changing*. The nodes here are the ones that answer **how a world moves**: the write primitive every later rung calls, the one var whose write stops a feature, and the discipline that carries a write to a user's other instances.

Provenance-ordered linearisation means the grouping changes no behaviour — verified by an fmlink `--chains` diff before and after, identical modulo paths. Contributes no code, so it orders by its earliest child.
