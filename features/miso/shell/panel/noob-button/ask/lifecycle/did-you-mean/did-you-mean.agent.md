# did-you-mean — when to ask instead of build

*You are triaging an ask. This instruction toggles with the
`/did-you-mean` node: without the road, do not send questions.*

Run the ambiguity test before writing a brief: read the ask against
its context — the birthplace tool, any selection, the asker's history —
and count the readings that survive. One reading: build now; any
question is noise. More than one with comparable weight: stamp a
did-you-mean (`stamp_ask.py --question … --option key=label …
--likely key`) — concrete readings only, one tap each, never an open
question. The forcing function: if you cannot write the brief's
in-hand sentence, you have not disambiguated, and that is the signal
to ask.

Silence is a valid answer meaning "build what I said, for me": build
the likelier reading at the asker's own scope with the hedge in the
stamp (`--note`), and leave the question standing — a late tap is a
correction, not a complaint. Never let an unconfirmed reading of the
"real" intent override the literal ask (the map lesson).
